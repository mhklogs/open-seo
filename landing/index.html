Self-host in one command

git clone https://github.com/mhklogs/open-seo.git
cd open-seo
cp .env.example .env
docker compose up -d
# → http://localhost:3001

Bring your own DataForSEO API key (new accounts get $1 free credit; min top-up $50, ~$5–15/mo for small sites). GSC integration is optional and free via your own Google OAuth client.
